# v178（2026-11-10 第三批）修快捷键"清了还报冲突"

## 用户报的 bug
清掉 A 功能的快捷键后，给 B 功能录同一个键时，仍提示"和 A 冲突"（A 明明已经清空了）。

## 根因
两处串起来：
1. `save_bindings()` 有守卫 `if d.get(k) != slots and (slots[0] or slots[1])`——
   **两个槽都清空**（空串）时整条被丢出 diff，等于"清了等于没清"。
2. `load_bindings()` / `default_bindings()` 用 `out[k] = [slots[0] or out[k][0], ...]`：
   即使盘上存了空串，`or` 回退到出厂值也会把被清的键**偷偷复活**。
→ 重开 F1 / 下次启动，`load_bindings` 把 A 的出厂键复活，于是 B 录同一个键还冲突。

## 改动（`ui/edit_shortcuts.py`）
- `save_bindings`：去掉 `(slots[0] or slots[1])` 守卫，全清空也要存（那是用户显式清掉）。
- `load_bindings` 覆盖循环 + `default_bindings` custom 覆盖：**显式清空的槽原样保留，不再复活**；
  仅极老的单值/单槽存盘（无备用键概念）才 `or` 回退出厂，保留其余槽。判定：
  `isinstance(v, str) or (isinstance(v,(list,tuple)) and len(v) < SLOT_COUNT)` 走老逻辑，否则直接采用。
- `merge/settings.py` 的 `save_edit_keys` 用 `{k:v if k and v}` 过滤，`["",""]` 是非空 list → 仍会落地，配合上方改动即可持久化。

  重载后该键都仍是空、且给 B 录同一个键时 occupied 不再含 A。

# v179（2026-11-10 第四批）V177 第 2/5 项"没执行成功" + 「默认开启」改造

## 用户反馈
- 「默认开启」要用 ✅ 勾选，删掉「取消」按钮。
- **V177 改的第 2、5 两项没执行成功**（第 2 条=轨道长按框选+素材框右键清空，第 5 条=关键帧截图变蓝）。

## 根因（v177 埋的 4 个坑，全部实测确认）
1. **关键帧截图变蓝永远不触发**：`Clip.nearest_keyframe(t)` 的 `t` 是**源文件**时间，
   而 `refresh_shot_keyframe_state` 传的是 `tl.playhead`（**时间线**时间）——
   两个坐标系不同，差整段片段的偏移（`start`/`src_in`/`speed`）。
   → 修：裁剪线→源时间→找关键帧→**关键帧换回时间线时间**再比容差。
   顺带把容差钳在 `[1/30, 0.12]` 秒（`_snap_tol` 随缩放变，pps 大时容差会大到离谱）。
2. **Ctrl+框选直接崩程序**：`dict.fromkeys(self._mq_prev + hits)` 去重，
   但 `Clip` 是 `@dataclass(eq=True)` → `__hash__` 被置 None → **不可哈希** → TypeError；
   这行在 `mouseMoveEvent` 里，PySide6 视为未捕获异常 → **整个程序 abort**。
   → 修：改用按身份(`is`)去重的 `_uniq_clips()`。
3. **长按框选几乎触发不了**：原来"鼠标一动超过 4px 就取消定时器"，真人手抖就超阈值。
   → 修：不再即时取消；定时器到点后回看位移，**没离开起点 6px(`LP_DRIFT_PX`)内**才进框选。
4. **素材框右键清空选中**：`QListWidget.setCurrentItem()` 在 ExtendedSelection 下内部走
   `ClearAndSelect` → 框选的一批被清得只剩当前一个。
   → 修：改用 `selectionModel().setCurrentIndex(idx, QItemSelectionModel.NoUpdate)`（只改 current 不碰选择集）。
5. 附带：Ctrl+点轨道空白原本会清空选中 → Ctrl 框选追加时"原来那批"就没了。→ Ctrl 时保留选中。
6. 附带：框选命中判定改用 `_clip_zone`（跟鼠标点击同一套矩形，含小字带），
   否则"框住名字却没框住片段"看着该选中的选不中；删掉被后面同名定义覆盖的**死代码** `_clip_rect`(旧 326 行)。

# v181（2026-11-10 第六批）右栏「轨道片段」三个交互 bug

  `_ctrl_held`；新增 `clear_selection()`（面板 / Qt 选中 / 轨道三处一起清）与公开
