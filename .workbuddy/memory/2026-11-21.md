# 2026-11-21 工作日志

## v261 — 统一参数配置弹窗非模态 + 文案精简 + 下拉浅蓝高亮

**需求**：打开「统一参数配置」后仍能操作主软件；「视频编码/音频编码/音频码率/音频采样格式」分别精简为「编码/编码/码率/采样格式」；弹窗下拉的当前项与悬浮项要有主界面同款蓝色高亮。

**根因**
- `main_window.open_norm_params()` 用 `dlg.exec()`，QDialog 默认 ApplicationModal，主窗口被锁。
- 文案写在 `norm_page.py` 的 `NORM_PARAM_ROWS` / `_NORM_GROUPS` / `_extra_controls()`，弹窗与顶栏不是同一处。
- 弹窗 `_DownComboBox` 没有委托。全局 QSS 的 `QWidget { background: transparent; }` 会把 QComboBox 弹层默认 selected 底色冲成白底；主界面顶栏下拉靠 `_CenterAlignDelegate` 自绘 `ACCENT_SOFT` 圆角底才显蓝，弹窗没接这条链路。只改 QSS（`::item:selected`）在透明弹层下无效，必须自绘。

**改动**
- `app/ui/main_window.py`：`open_norm_params()` 改为单一实例 + `show()` + `Qt.NonModal` + `WA_DeleteOnClose`；重复打开只置前；新增 `_forget_norm_params_dialog(token)`，避免旧实例的延迟销毁回调清掉新实例引用；点保存时 `accept()` 会关窗释放，下次打开自然重建。
- `app/ui/dialogs.py`：新增 `_ComboHighlightDelegate`（左对齐版，逻辑与主界面 `_CenterAlignDelegate` 同款：当前项/悬浮/选中铺 `T.ACCENT_SOFT` 圆角底，随后清状态再交基类渲染）。
- `app/ui/normalize_dialog.py`：`_DownComboBox.__init__` 挂该委托并给弹层开 `setMouseTracking(True)`，统一参数弹窗与老 NormalizeDialog 的所有下拉一并生效；顶栏 combo 仍用居中版委托，不受影响。
- `app/ui/norm_page.py`：4 处文案精简（含 codec 分组标题）。顶栏 `_combo_defs` 文案未动（不是本次弹窗范围）。
- `app/__init__.py`：build 260 → 261。

**验收**
