## v116（剪辑态第二轮：修坑 + 关键帧 + 播放 + 分离音频 + 改键）
- **空格导致退出剪辑态**：根因不是快捷键冲突，是 Qt 老毛病——点过按钮后焦点留在按钮上，**空格 = 再点一次它**（点完「剪辑」再按空格就退出了）。修法：`_kill_button_focus()` 把主窗口所有 QPushButton/QToolButton 设 NoFocus（ToolButton 构造里也设），空格改绑播放/暂停。⚠️ 凡是"点完某按钮再按空格出事"，先查 focusPolicy。
- **缩放到最小 = 全览**：`MIN_PPS` 从写死 2.0 改成 `min_pps() = max(0.05, fit_pps())`，`set_pps` 夹在这个动态下限上；`resizeEvent` 里重新 `set_pps(self._pps)` 夹一次（窗口变窄下限跟着变）。
- **关键帧可视化**：`probe.probe_keyframes` = `ffprobe -skip_frame nokey -show_entries frame=pts_time -of csv=p=0`；`ClipProbeWorker` 一次返回 `{duration, keyframes, has_audio}`（信号改 `one(str, object)`）；`Clip.keyframes/src_duration`；时间线画红线时刻度。⚠️ 1px 竖线必须 `setRenderHint(Antialiasing, False)`，否则被抹成两个半透明像素，又虚又测不出来。
- **边缘裁剪**：`timeline._trim_side/_apply_trim`（左右 6px 热区、SplitHCursor）；视频/音频吸附最近关键帧，气泡当场显示「实际切在 00:04.0，偏差 1.0 秒」（`_paint_trim_bubble`，边框红=有偏差/绿=落在关键帧上）；图片只裁尾巴（改 hold，`_side_ok` 挡左边缘）。同轨首尾相接，裁完自动波纹收缩。
- **右键菜单**：`contextMenuRequested(clip, globalPos)` → `_on_edit_context_menu` → **`_edit_clip_menu(clip)` 单独返回 QMenu**（离屏测试要能看菜单内容，`QMenu.exec` 在 PySide6 里 monkey-patch 不掉，真 exec 会挂住）。项：分离音频 / 删除原音(静音) / 在播放头处分割 / 删除 / 在文件夹里显示。
- **分离音频**：`ExtractAudioWorker` 走 `-vn -map a:0 -c:a copy`，输出到源文件同目录 `原名_音频.m4a`（编码→扩展名映射 aac→m4a / mp3 / ogg / flac，认不出的才转 aac 并明说）。成功后作为音频片段进音频轨。
- **播放**：**不引 QtMultimedia**（打包会漏后端插件）→ `ui/player.py::FramePlayer` 起 ffmpeg 输出 `-f rawvideo -pix_fmt rgb24` 到管道，QThread 按 frame_size 读、`.copy()` 成 QImage 发主线程；640 宽等比、15fps；图片/音频片段用 QTimer 推播放头。⚠️ **播不出来必须往前挪一段再试**（`_on_player_ended` 里 `playhead = max(playhead+0.05, clip_end)`），否则原地重启 ffmpeg = 死循环（第一版真踩了，跑 8 分钟不结束）。
- **改键**：`edit_shortcuts.ACTIONS`(id/默认键/说明/分组) + `load_bindings/save_bindings`(merge.json::edit_keys，只存与默认不同的)；F1 面板里每行键位是 `_KeyButton`，点一下 `grabKeyboard()` 进入捕获，冲突拦下、Backspace 清空、可一键恢复默认。⚠️ PySide6 里 `QKeySequence(int(key)|int(mods))` 会 TypeError（KeyboardModifier 不能 int()）→ 改成手拼 "Ctrl+Alt+Shift+名字"。
- **按钮收拾**：只摆能用的 6 个（播放/分割/删除/全览/添加素材/快捷键），删掉裁剪(未做)/上一帧/下一帧/放大/缩小；顺手把「显示方式」下拉在合并形态隐藏。
