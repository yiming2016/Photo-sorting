## v225 — 顶部"日"开关补"自动开月"级联

用户反馈：排序下点了顶部"年"再点"日"，"月"没有被正常开启。要求检查类似 bug。

根因（复现确认）：
1. `_on_master_toggle` 没有"开日自动开月"级联——组标题路径（`_on_group_toggle`）和统一页（`_on_norm_group_toggle` 开帧率自动开分辨率）都有，唯独顶部开关这条漏了。且更糟：月关着时点"日"，`if not month: sw_day.setChecked(False)` 会把"日"**立刻弹回去**（开关没亮），但外层那次 `set_master` 仍把 `master["day"]` 写成 True——开关与 model 状态不一致。
2. 修第一处时发现第二处：级联递归（关月→关日）后，外层帧用进入时读到的旧值调 `set_master`，**覆盖递归内层**写好的正确状态（关月后 master.day 仍是 True）。

修复（提交 `ed61a4e`）：
- `_on_master_toggle` 补 `if _name == "day" and day and not month:` 自动开月（用信号传入的 `_name` 限定，防止"关月连带关日"等关闭级联被反向弹回——第一版漏了这个，关月被弹回开）。
- 落盘改 `set_master(self.sw_year/month/day.isChecked())` 即开关**最终状态**，不再用局部旧值。

验收：`out/repro/verify_v225.py` **18 项全过**（开日自动开月/开关不弹回/master 一致/日级分组出现、月独立行为、关月关日/关年关月日含 master 断言、组标题路径回归、统一页帧率 disabled 口径回归），入 `_run_all.py`。全量只剩长期 5 个 safe-delete。
- ⚠️ 沉淀：共享 toggled 处理器里做级联要区分**触发源**（信号参数 `_name`），且落盘要在级联后读开关最终状态——局部变量在递归后全是旧值。

类似 bug 排查结论：统一页顶栏"帧率"在分辨率关着时是 disabled（点不了），不存在同类不一致；剪辑窗口无层级开关。打包 v225 已部署，标题 `照片排序台 v225`。可回退：`out/部署前软件_v224`。


## v226 单文件子组紧凑卡 + 「独立」文案（用户第 4 轮）

需求：① 分组下子组只有一个文件却占一整行 → 一行显示 2 个/多个子组，且原有内容一项不丢；② 合并模块"单独一个"不显示"1 段"、"单独一个"→"独立"、顶栏板块"单独"→"独立"。

实现：
- **PackRow(PhotoRow 子类)**（`core/photo.py`）：字段 `header: HeaderRow`。叶分组只有 1 个可见文件且**不在第 0 层**（排序=月/日级、统一=分辨率/帧率级；合并组都 level 0 但 merge_tag 非空 → 可打包）时，组头+唯一卡合成一格。三条铺行路径（rebuild 排序 / _rebuild_norm / _rebuild_merge）各加 pack_leaf 判定：`counts[leaf]==1 and max_depth>=2 and not collapsed_found`，父级标题铺到 `max_depth-1` 层。折叠的叶组不打包（满宽折叠标题）。**继承 PhotoRow 是关键**——选择/拖拽/缩略图/_grid_sel_paths/props 顺序等所有 isinstance(PhotoRow) 路径自动兼容，只改了 `_sync_group_checks` 两个循环（PackRow → row.header）。
- **delegate.py**：`pack_layout`（三角/勾选框矩形，绘制与命中共用）、`pack_lines`（组头按卡宽折行，返回 [[(text,color_key,size,demi,lv),...]]）、`pack_header_h`（测高=折行数）、`hit_test_pack`（三角/勾选框/兜底 collapse）、`draw_pack`（上半组头折行+下半 draw_photo 复用，用 QStyleOptionViewItem 拷贝平移 rect）。sizeHint = cell_w × (组头高+cell_h)。合并单文件组头**不写"1 段"**（draw_header 也改：`row.count > 1` 才画"N 段"）。
- **grouplist.py**：mousePress/doubleClick 先判 PackRow——pos 在组头区（`pack_header_h`）走 `hit_test_pack` 路由 collapse/groupcheck，否则当照片走原逻辑；`_hover_cursor` 自动兼容（全卡抓手）。
- 文案：`grouping.build_merge_groups` "单独一个"→"独立"；main_window 顶栏 QLabel/tooltip/消息、props_dialog "单独一段"→"独立一段"、theme.py 注释。

## v227 合并独立卡层级版式（用户第 5 轮，中途追加"只有编码居右"口径）

需求：① 注意层级，同一层级保持水平；② 合并页独立卡的编码格式居右（后来细化：**只有编码格式居右、与组名同行**，其余规格段居左开始）；③ 所有"独立"另起一行（不和"可无损合并"的照片同排）；④ 独立收起后不占整行（保持紧凑格式）。

实现：
- **RowBreak**（`core/photo.py` 新行类型，非 PhotoRow）：`_rebuild_merge` 在紧凑卡前且 `rows[-1]` 是普通 PhotoRow 时垫一条——视口同宽正好占满一排 → 后面卡片自然换行；高 4px 不绘制；flags=ItemIsEnabled（不可选/拖），data() 除 ROLE_ROW 全 None。⚠️ 新行类型必须同步 data()/flags() 守卫，否则 Qt 布局查 DisplayRole 会炸在 row.photo。
- **统一头高**：`ThumbDelegate._merge_pack_uni_h()`（缓存键 = (cell_w, rows 列表对象)）= 所有合并 PackRow 头高最大值；合并展开卡 sizeHint = uni+cell_h，收起卡 = uni。文本贴底（bottom-anchor）：`pack_layout` 的 off = max(PAD_TOP, head_h - n*LINE_H - PAD_BOTTOM)，自然高度时退化回 PAD_TOP（向后兼容）。同排照片同顶=水平 ✓。
- **头区命中**：`GroupView._pack_head_h`——合并展开=卡高-cell_h，收起=整卡，排序/统一=自然高；press/doubleClick 共用。
- **口径**：`pack_lines` merge 分支重构——首行 = [组名(+N段)] + [编码段]（head_w≤avail 才同行，否则整体流式），其余段 flow 居左；`draw_pack` 首行 label 左 + line[1:] 贴右缘，其余行 tx 左对齐。
- 收起的独立组仍是 PackRow（collapsed=True 传进 header），draw_pack 收起只画头块；`toggle_collapse`→rebuild→rows 新列表→uni 缓存自然失效。

验收：`verify_v227.py` 32 项全过（另起一行/收起紧凑/RowBreak 行为/几何兼容/头区命中/全选不含换行条/主窗口勾选同步/绘制不崩），入 `_run_all.py`；v218 一条 rowCount 断言按新口径改（收起后=2 行：折叠标题+紧凑卡）；v226 复跑 39 项全过。全量基线恢复（长期 5 个 safe-delete）。离屏截图目视：首行"独立"+编码贴右、其余规格左流、照片同水平。

## v228 紧凑卡文字对齐 + 顶栏重叠 + 统一/排序紧凑卡另起一行（用户第 6 轮，3 个问题）

需求（3 张截图）：① 合并两张不同帧率的"独立"卡横向文字没对齐，且规格文字没"居左到头（选中方块下面为最左）"；② 点"合并"再点"统一"，顶栏按钮重叠（开关叠在参数条上）；③ 统一页编码/分辨率相同、帧率不同：30fps 组（2 文件）的照片行后跟 50fps 单文件紧凑卡，帧率组标题错位。

根因与修复：
- **A 文字对齐**：v227 的 bottom-anchor 在同排卡折行数不同（59.94fps 串更宽多折一行）时首行"独立"高低不一 → `pack_layout` 改回**顶部锚定**（off=PACK_PAD_TOP 恒定）；统一头高不变、照片仍水平，富余挪到卡头底部。续行（第 2 行起）起点 = **PACK_CONT_X（勾选框左缘下方）**——draw 时必须 `head_rect.x() + PACK_CONT_X`（⚠️ 相对坐标忘加卡偏移会把第二张卡的规格行画到第一张卡上，截图目检抓出来的）。小格宽兜底：flow() 里单段宽过卡缘时 `elidedText` 截断，绝不溢出到邻卡。
- **B 顶栏重叠**：`norm_param_slot` 曾 `SetFixedSize` 锁死（810×39，min=max），默认 1700 窗口下顶栏（参数条+开关+滑块最小 ≈1560）分不到空间，槽被顶死缩不回去 → 开关直接叠上来（v214 起就存在，用户现在才报）。修复：新增 **`NormParamSlot`**（norm_page.py）——`minimumSizeHint` 压到很小（每格 56px 下限），`resizeEvent` 里按比例把 4 个 combo `setFixedWidth` 缩放（富余时精确回 fit 宽度=文字 100% 完整，挤压时整体缩、不外溢）；`_build_topbar` 换用它（`register(panel.param_cells())`）。默认窗口 1700→**1800**（v213 口径"文字完整"在 1800 全部成立）。combo 弹出菜单 `view().setMinimumWidth(sizeHint)` 保长选项完整。⚠️ Qt 拉伸分配不走寻常路（stretch/hint 组合实测非单调，试了 4 种组合都歪）——**确定性缩放比 layout 魔法可靠**。
