# 照片排序台

<p align="center">
  <img src="源码/tools/logo.svg" width="110" alt="照片排序台 logo">
</p>

手动拖拽排序照片 / 视频，一次性把时间戳写回 EXIF / XMP / QuickTime / 文件系统，让安卓相册、Windows 照片、Mac 照片等按你指定的顺序显示。

## 功能特性

- **拖拽排序**：在主网格里自由拖拽，决定每张照片的先后顺序（列表第 1 张 = 最新）。
- **时间戳写回**：支持 修改时间 / 创建时间 / 拍摄时间（EXIF、XMP、QuickTime 与文件系统时间全部写入）。
- **时间分配**：可手动指定起始时间，或「自动间隔分配时间」按序号均匀铺开。
- **分组展示**：按 年 / 月 / 日 分组（可叠加），方便核对顺序。
- **回滚快照**：每次写入前自动保存元数据快照，可一键还原，不复制原文件。
- **图片 + 视频**：照片（含 HEIC）与视频（含 MOV / MP4）均支持。
- **时区处理**：界面全部按北京时间显示，写入时自动转换为 UTC。
- **更多**：按 文件名 / 拍摄时间 / 文件大小 多种排序，文件名过滤，缩略图缓存，多来源累加。

## 下载与安装

前往 [Releases](../../releases) 下载最新「软件包」压缩包，解压后双击 `照片排序台.exe` 即可运行（Windows 64 位，无需安装、无需 Python 环境）。

## 使用步骤

1. 点击「添加」选择文件夹或文件（也可直接把文件拖进窗口）。
2. 在主网格里拖拽，排好你想要的先后顺序。
3. 分配时间：在「排序 ▾」菜单选择排序方式，或「自动间隔分配时间」按起始时间均匀分配。
4. 点击「写入到文件」，把时间戳一次性写回（写入前会自动保存回滚快照）。

## 快捷键

| 快捷键 | 功能 |
| --- | --- |
| Ctrl+O | 打开文件夹 |
| Ctrl+Shift+O | 打开文件 |
| Ctrl+I | 自动间隔分配时间 |
| Ctrl+Enter | 写入到文件 |
| Ctrl+R / F5 | 重新扫描 |
| Ctrl+Shift+R | 清除计划 |
| Ctrl+A | 全选 |
| 右键 | 排序 / 间隔 / 全选 / 移除 / 删除 |

## 从源码构建

环境要求：

- Python 3.13
- [ExifTool](https://exiftool.org/)（放到 `源码/tools/exiftool.exe`；`build.bat` 会自动从 `C:\Program Files\ExifTool` 复制）
- 依赖：PySide6、pillow、pillow-heif

步骤：

```bash
cd 源码
# 1. 复制 ExifTool 到 tools/（若未自动复制）
# 2. 一键打包
build.bat
# 产物在 软件/照片排序台.exe
```

打包脚本会生成多尺寸应用图标（`tools/logo.ico`）并扁平化部署到 `软件/`。
